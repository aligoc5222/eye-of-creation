Bir gözün içine dalıp evrenin doğuşuna giden, ardından kara deliğin içinden tekrar o göze dönen ASCII sinematik döngü. Python + pygame ile çalışıyor.


    EYE → CREATION → BIG BANG → GALAXY → BLACK HOLE → EYE

🚀  ÇALIŞTIRMA

Python 3.9+.

```bash
pip install -r requirements.txt
python eye_of_creation.py
```

## 🎮 Controls

| Key | Action |
|---|---|
| Mouse | The eye follows you. In CREATION you steer God's hand. |
| Click | Blink |
| `SPACE` | Pause |
| `→` | Skip to the next world |
| `↑` / `↓` | Time speed |
| `+` / `-` | Glyph size (detail vs. speed) |
| `C` | Colour mode: Cosmic, Matrix, Amber, Inferno, Prism |
| `B` / `G` / `H` | Bloom / CRT scanlines / HUD |
| `S` | Screenshot |
| `R` | Record PNG frames at 30 fps (prints the ffmpeg command to make a video) |
| `F1` | Help |
| `ESC` | Quit |
